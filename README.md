# 西贝 / MrSibe

写 Go 和 TypeScript，做本地优先的 AI 工具。在成都，喜欢天文观测。

## 项目

- [KnowNote](https://github.com/MrSibe/KnowNote)：本地优先的 AI 知识库桌面端。文档解析和检索在本机完成，答案带回原文出处。
- [GOAT](https://github.com/MrSibe/goat)：Go 的 Agent SDK，同一套代码接 OpenAI、Anthropic、Gemini 或自建模型。
- [goding](https://github.com/MrSibe/goding)：基于 GOAT 的编码 Agent。
- [SkyEye](https://github.com/MrSibe/sky-eye)：小行星观测用的桌面软件。读 FITS、解 WCS、做测光，生成 MPC 观测报告。

## 其他项目

- [godis](https://github.com/MrSibe/godis)：Redis 兼容的内存 KV 存储。
- [mira](https://github.com/MrSibe/mira)：用自己的 API Key 的 ChatGPT 桌面客户端。
- [streamgate](https://github.com/MrSibe/streamgate)：IPTV 流网关。
